Seattle Weather Dashboard

Personal project · React · Oct 2026

Open live demo View code on GitHub

Overview

An interactive dashboard for exploring four years of daily weather in Seattle (1,461 days, 2012–2015). Choose a year and a weather type, and the summary tiles, three charts and a data table all update together.

Why I Built It

I'm applying for web developer and data analyst roles, and I wanted one project that shows both sides: React for the interface and data analysis for the numbers. I used real public data so every figure can be checked, and I drew the charts in SVG myself, without a chart library, to understand how they work.

I built this with an AI coding assistant, then read, tested and changed the code so I can explain how each part works.

What It Does

  • Filters: year and weather type in one row; everything below updates to match
  • Summary tiles: average daily high, total precipitation, days with precipitation and the hottest day, with the change from the previous year when one year is selected
  • Charts: monthly temperature (line), monthly precipitation (columns) and days by weather type (bars), with hover tooltips and keyboard navigation
  • Table view and CSV export: every number the charts draw, readable without hovering, plus a download of the selected days
  • Light and dark mode that follow the system setting, and a layout that works on a phone

Screenshots

Phone layout: tiles and charts stack into one column.

How It's Built

  • Data logic in plain functions: CSV parsing and validation, filtering, monthly averages and totals, and year-over-year change, covered by unit tests
  • React hooks: loading and error states for the data, useMemo so numbers are recalculated only when filters change, and a custom hook for keyboard and pointer focus on charts
  • Charts from scratch in SVG: scales, round axis ticks and gaps for months with no matching days (a gap, not a false zero)
  • Accessibility: a table view for every chart, labelled controls, visible focus and screen-reader announcements
  • Automatic testing and deployment: every push runs the tests, builds the app and publishes it to GitHub Pages

About the Data

Daily weather summaries for Seattle from NOAA, taken from the open-source vega-datasets package (U.S. government data). The weather type (sun, rain, snow and so on) was derived from the original measurements by the dataset's authors, and the dataset is intended for teaching, so treat the numbers as an example rather than an official climate record.
