Tool Rental Web App

Team project · CST8285 Web Programming · Jul–Aug 2025

Overview

A dynamic web application for a fictional tool rental company, built by a team of three for a Web Programming course. Customers can browse an inventory of tools, search and filter it, and place, edit and delete rental orders that are stored in a MySQL database.

My Role

I focused on the design side of the project: planning how the site should look and work, and turning that plan into HTML and CSS.

  • Created the site map, the wireframes and the functional diagram before development started, so the team agreed on the pages and flow
  • Wrote the semantic HTML structure for the site's pages (header, navigation, main content and footer)
  • Designed and wrote the CSS: a single external stylesheet using CSS variables and a responsive layout with media queries

My two teammates built the database and testing, and the JavaScript form validation.

What the Team Built

  • Inventory: a tool table with search by name and filters by category and location
  • Rent orders: create, edit and delete orders, with the total cost calculated from the daily price, quantity and rental dates
  • Form validation: client-side validation with clear error messages on the login and sign-up forms
  • Other pages: home page, customer testimonials, terms and privacy, and a contact page
